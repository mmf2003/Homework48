# Task Manager

A simple responsive Task Manager application built with React, Vite and Material UI.

The application allows users to create and delete tasks. It also includes form validation and automatically displays the current number of tasks.

## Technologies

- React
- Vite
- Material UI
- JavaScript

## Features

- Add new tasks
- Delete tasks
- Form validation
- Task counter
- Responsive design
- Material UI components

## Installation

```bash
npm install
npm run dev
```
